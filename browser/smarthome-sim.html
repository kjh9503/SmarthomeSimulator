Phone

The person's phone. Each action below adds phone events (event-formats). Travel takes simulated time (walking and waiting legs, the ride, legs after); run or step the clock to see the trip happen. Every saved home log line is also copied to the phone as a SMARTTHINGS event. Battery, weather and location go on every phone event as context. To control a home device from the phone, pick a device on the plan and set "Control from" to Phone app.

Typing a time jumps there without simulating the gap; the +min/+hour/+day buttons simulate it. The log is kept temporarily in this browser; save it to use it as data. It saves as .txt because of a file-type limit; the content is one JSON object per line (JSONL).
